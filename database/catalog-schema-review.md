# Ревизия структуры каталога Tea Market

В миграцию `100_catalog_foundation` собраны изменения, которые нужны до продолжения API каталога и будущей админ-панели.

## Добавлено

### `product_variants`

- `old_price` — старая цена конкретного веса;
- `is_available` — ручное отключение продажи варианта без удаления;
- `status` — `active`, `hidden`, `archived`;
- проверки и индекс для получения доступных вариантов карточки товара.

Остаток по-прежнему хранится в `stock_quantity`. Поэтому вариант может быть активным, но временно отсутствовать на складе.

### `categories`

- обязательный уникальный `slug`;
- `seo_title`, `seo_description`, `canonical_url`, `is_indexed`;
- индекс для API каталога.

Для уже существующих категорий миграция создаёт технический slug вида `category-<uuid>`. Его нужно будет заменить через админ-панель.

### `collections`

- обязательный уникальный `slug`;
- тип `manual` или `automatic`;
- JSON-правила автоматической подборки;
- активность, показ на главной, даты публикации;
- SEO-поля;
- проверки и индексы.

Для существующих подборок создаётся технический slug вида `collection-<uuid>`.

## Не добавлялось

Не создавались универсальные таблицы произвольных характеристик. Текущая карточка чая уже покрывается полями `products`, а преждевременная EAV-структура заметно усложнила бы API и админ-панель.

Не менялись таблицы заказов, корзин, покупателей, доставки и оплаты: найденная структура согласована и достаточна для следующих этапов API.
